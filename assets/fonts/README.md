# Fonts

The website serves these itself, so no page waits on a third-party stylesheet. Latin subsets of the variable fonts from Google Fonts, all under the SIL Open Font License 1.1:

- `stack-sans-text.woff2`: Stack Sans Text (headings)
- `geist.woff2`: Geist (text)
- `geist-mono.woff2`: Geist Mono (figures)
